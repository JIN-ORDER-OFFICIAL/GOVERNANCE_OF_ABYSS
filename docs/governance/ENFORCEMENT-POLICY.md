# JIN-ORDER 不正利用・盗用に対する調査及び権利行使方針
### (JIN-ORDER IP & Policy Enforcement Policy)

- **策定:** 一般社団法人JIN-ORDER 監察監査部
- **関連規約:** [JIN-ORDER Dual License V8.3-A](../../LICENSE.md)
- **対象仕様:** SPEC-004 (PAP), SPEC-005 (CNP), JIN-ARTERIAL, JIN-COMMERCE, SMCP 等

本方針は、当法人が公開する先行技術、公共設計資産、都市インフラ連携プロトコル、および越境中立モデル（JIN-ORDER体系）が、出所を偽った政策ロンダリング、受託コンサルタントによる成果物偽装、物理インフラへの過負荷外部化、または一方的アクセス遮断に晒された場合における、具体的な調査・追及・法的執行手続きを定めたものです。

---

## 1. 先行技術防壁（Prior Art）の行使
当法人の公開資産は、GitHubの確定コミットログおよびWayback Machine（世界魚拓）による確定タイムスタンプを有しています。
第三者による無断特許出願や規格独占が確認された場合、特許法に基づき以下の措置を機械的かつ迅速に執行します。

* 特許庁審査官に対する「刊行物等提出書（特許法規に基づく情報提供）」の即時提出
* すでに成立した特許に対する特許無効審判（特許法第123条）の請求
* 審判請求書および客観的証拠資料のオープン公開

## 2. 政策ロンダリング・成果物偽装への調査手順
国、地方自治体、シンクタンク、建設コンサルタント、ITベンダー等が、当法人の仕様と実質的一体性を有する施策・モデルを、出所を隠蔽して公的予算や成果物として公表した疑いがある場合、以下の行政法規に基づく事実調査を行います。

1. **公文書開示請求（情報公開制度の活用）:**  
   当該施策の策定経緯、有識者会議議事録、受託民間企業との仕様書・契約書・設計計算書の完全開示を請求し、参照元データの痕跡を法的に特定します。
2. **出所明示の是正勧告:**  
   開示情報に基づき盗用または実質的翻案が認められた場合、発注元行政機関および受注民間企業に対し、連名で「出所（一般社団法人JIN-ORDER）の追記」および公式見解の提示を正式に勧告します。
3. **会計検査院および行政監査機関への情報提供:**  
   出所偽装や成果物盗用に基づく公金（委託費・補助金）の不正・不当支出の疑いがある場合、会計検査院法および地方自治法に基づく監査請求・情報提供を実施します。

## 3. インフラ過負荷・アクセス遮断に対する監査・執行手順（SPEC-004 / SPEC-005 連動）

### 3.1. 都市物理インフラ過負荷（SPEC-004違反）の追及
計算資源の運用者が地域インフラ（電力網・上下水道・道路地下空間）に過度な負荷を外部化し、減災協調義務を怠った疑いがある場合：

1. **テレメトリ・インフラログ照合:**  
   自治体下水道管理者（雨水管路水位）、電力系統運用者（DSO）、および道路管理者（道路法第32条占用許可台帳）の公開データと、当該ノードの稼働ログの突き合わせを実施します。
2. **原状回復及び賠償請求:**  
   ライセンス第6条に基づき「不可抗力免責」の主張を否認し、インフラ損傷（路盤変状、冠水被害、過熱による設備劣化等）に対する原状回復費用および損害賠償請求の手続きを支援・執行します。

### 3.2. 地政学的遮断・公共通信検閲（SPEC-005違反）の追及
国家の制裁命令や特定独占資本の意図に従い、人道・防災データ（JCPP）の通信を一方的に遮断・検閲した場合：

1. **メッシュ通信ログ監査:**  
   P2Pルーティングの切断履歴およびゼロ知識証明（ZKP）の不当破棄を検証・特定します。
2. **JIN-Certificateの剥奪と隔離:**  
   違反ノードのJIN-ORDER相互接続認証を即座に失効させ、グローバルメッシュから隔離措置を講じます。

## 4. 事実公表（ノーマスキング監査レポート）の基準
是正勧告に対して真摯な対応がなされず、意図的な出所隠蔽、アイデアの盗用、インフラ負荷の外部化、または人道通信の遮断が継続されたと客観的に判断される場合に限り、当法人は以下の自衛的公表を行います。

* 調査によって確定した客観的事実関係（関係組織名、開示された公文書の内容、インフラ負荷データ、およびJIN-ORDER先行技術との対照表）を、JIN-ORDER監査レポートとして公式公開します。
* ※主観的な誹謗中傷や推測に基づく断定は厳に排し、公文書開示データおよび先行技術の客観的比較に限定して公表します。
