### 2.1 拡張電力グリッド飽和指数 (GSI 2.0) の数理モデル

計算拠点の持続性と地域生存圏の受忍限度を統合評価するため、水資源消費、生活圧迫係数、戦略装備の供給制約、および主権流出リスクを組み込んだ拡張モデルを定義する。

$$GSI_{2.0} = \frac{D_{compute} + D_{industrial}}{C_{transmission} \times (1 - \lambda_{congestion})} \times \theta_{regulatory} \times \phi_{material} \times \psi_{cannibalization} \times \omega_{sovereignty}$$

- **$D_{compute}$**: 対象地域における予測AI計算需要電力 (MW)
- **$D_{industrial}$**: 既存産業・民生電力ベースロード需要 (MW)
- **$C_{transmission}$**: 系統変電・高圧送電公称最大容量 (MW)
- **$\lambda_{congestion}$**: 送電損失・熱歪み・系統混雑係数 ($0 \le \lambda < 1$)
- **$\theta_{regulatory}$**: 環境アセスメント・住民投票凍結・地域合意形成遅延ペナルティ係数 ($\ge 1.0$)
- **$\phi_{material}$**: 大型変圧器（GSU）・珪素鋼板・高圧導体、ならびに**2026年11月発動のシールド掘削機・水処理設備輸出規制に伴う調達遅延・経済安保リスク係数 ($\ge 1.0$)**
- **$\psi_{cannibalization}$**: **【新設】水資源枯渇・市民生活電力共食いペナルティ係数 ($\ge 1.0$)**
- **$\omega_{sovereignty}$**: **【新設】計算租界化（域外管轄権・クラウド遠隔アクセス規制による現地資源収奪）ペナルティ係数 ($\ge 1.0$)**

$$\psi_{cannibalization} = 1 + \alpha \left(\frac{W_{evaporative}}{W_{sustainable}}\right) + \beta \left(\frac{\Delta Cost_{civilian}}{Cost_{base}}\right)$$

- $W_{evaporative}$: 冷却用蒸発・消費水量 ($m^3/\text{day}$)
- $W_{sustainable}$: 流域の持続可能許容取水量 ($m^3/\text{day}$)
- $\Delta Cost_{civilian} / Cost_{base}$: 市民家庭・中小事業者の電気料金上昇率

**動向分析（2026年11月更新）:**  
米バージニア州やアイルランド等では $GSI_{2.0} > 2.5$ に達し、市民の電気・水道料金高騰に対する社会的反発とDC新設モラトリアムが顕在化している。<br>さらに2026年11月18日の中国・公告2026年第50号によるシールド掘削機等の輸出管理発動と逆浸透式水処理設備の国産基準化は、大型地下掘削や中央集権型水処理プラントを前提とする巨大開発の $\phi_{material}$ を一気に跳ね上げた。<br>また、前線同盟国において外資ハイパースケーラーが100MW〜500MW級の電力を囲い込む「計算租界」モデルでは $\omega_{sovereignty}$ が急上昇し、有事や米国の遠隔アクセス規制発動時に現地自治体が自らの電力・通信・計算網の制御権を失う構造的脆弱性が露呈している。<br>この結果、計算資源の立地は「資本の集中地」から、「エネルギー・水・非開削現場インフラが自律共生できる主権特区」へと強制移転を余儀なくされている。
