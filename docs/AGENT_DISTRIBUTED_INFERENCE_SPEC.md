# AGENT DISTRIBUTED INFERENCE & CONSENSUS PROTOCOL (ADICP-01)
*Decentralized Cognitive Architecture for JIN-ORDER Autonomous Nodes*

---

## 1. 概要と設計目標
本仕様書は、巨大ハイパースケーラーの集中型API・モデル検閲・計算リソース遮断に対抗するためのプロトコルである。
ローカルエッジノード群がP2Pメッシュを形成し、推論のパイプライン並列実行と数学的出力検証を自律完結させる。

---

## 2. 分散推論アーキテクチャ（Distributed Inference Pipeline）

### 2.1. モデルシャーディングと動的レイヤー配置
* **動的テンソル分割**:
  巨大フロンティアモデルを単一マシンで保持せず、複数ノードのVRAM/NPUへレイヤー単位で分割（Model Sharding）して保持。
* **トポロジー認識型ルーティング**:
  エッジノード間の通信遅延（RTT）と帯域幅を常時監視し、推論パイプラインの経由順序を自律最適化。

### 2.2. ハイパースケーラー・フォールバック遮断
* 外部メガクラウドへの接続が遮断された場合、直ちに「完全局所メッシュ推論（Air-gapped Edge Swarm）」へ自動切替。
* 小型SLM（Small Language Models）同士のアンサンブル合意形成を用い、大規模モデルに近い論理整合性を維持。

---

## 3. トラストレス検証と合意形成（Verifiable Inference & Consensus）

### 3.1. 推論証明（Proof of Inference: PoI）
* 推論を実行したノードは、計算過程の正当性を示す軽量ゼロ知識証明（zk-STARKs）または暗号化中間活性化署名を生成。
* 下流ノードは中間出力を再計算することなく、署名検証のみでトークン生成の改ざん・幻覚注入を検知。

### 3.2. 悪意・汚染ノードのスラッシング
* 誤った推論結果や敵対的プロンプト操作を試みたノードは、分散台帳のレピュテーションスコアを即時剥奪。
* 該当ノードはコンセンサスメッシュから除外され、ルーティングテーブルより遮断。

---

## 4. 遅延耐性データ同期（Delay-Tolerant State Sync）

### 4.1. ゴシッププロトコルによる非同期合意
* ノード群が間欠的・断続的な通信状態にある場合、Gossipプロトコルによりモデル更新差分（LoRAアダプタ等）をエピデミック（感染的）に伝播。
* 全体ノードの疎通が回復した際、CRDT（競合解消フリー複製データ型）を用いて推論コンテキストの整合性を回復。

### 4.2. オフライン署名付きコマンドキュー
* 通信切断下で下されたエージェントの自律判断は、ローカルハードウェア暗号化モジュール（TPM / Secure Enclave）で署名。
* 再接続時に一括提出され、事後監査可能性を恒久保証。
