Status: CLANDESTINE / DEPLOYED
Category: Underground Asymmetric Logistics & Conduit Architecture
Maintained By: Sub-Surface Logistics Guild ("Mud-Divers")

## 1. Overview
本仕様は、ACVAおよび主幹条約機構による「VOID-STRANGLE（環流遮断）」下において、
完全孤立状態に置かれた非公認セクター間を物理的・流体的に再結合するための地下回廊規格である。

## 2. Structural Layer Specifications
### 2.1 Conduits & Casings (導管・覆工)
- **Base Structure:** 旧規格暗渠（廃止放水路・雨水幹線）の再利用。
- **Inner Lining:** 3層複合ライニング工法（フェライト電磁遮蔽層 + 断熱発泡エラストマー + 超平滑耐摩耗層）。
- **Acoustic Signature:** 導管外周に多孔質防音スリーブを充填し、流動騒音を暗振動（Ambient Noise）以下に抑制。

### 2.2 Covert Tap-In Protocols (不断流分岐)
- **Operation "Leech":** 広域送水・冷媒バイパス管への非公認穿孔。
- **Pressure Balancing:** 奪取した純水・冷却材と等容量の処理済排水を逆位相パルスで注入し、
  中立管路の質量収支モニターにおける検知トリガー（Variance > 0.02%）を回避。

### 2.3 Logistics Payload (搬送体)
- **Model:** SC-04 "Siphon-Runner"
- **Propulsion:** 流体差圧（Head Loss Differential） + 自律バラスト可変浮力
- **Payload Capacity:** 冷却冷媒カートリッジ、暗号化自律核メモリブロック、高純度基盤素材

## 3. Defense & Self-Purge (防諜・自爆機構)

流路を天然の滞水砂礫層へ偽装消滅させる。
