## 0. 目的と法的無効化理論（Legal Nullification）

行政・警察が路上や公園の避難民・困窮者を排除する際の根拠法令は、主として以下の3点である。

1. **民法第86条第1項（不動産の定義）**: 「土地及びその定着物は、不動産とする。」
2. **道路法第32条・第43条 / 都市公園法第6条**: 道路・公園における工作物の無許可占用・禁止行為。
3. **行政代執行法第2条 / 道路法第71条**: 戒告・通知を経て工作物を強制撤去・除却する執行権。

これら法執行の要件は、いずれも対象が**「土地に定着した工作物（建築物）」**であることに依存している。  
本仕様は、物理構造から「定着性」「恒久性」を完全剥奪し、「展開（Deploy）15分・溶解（Melt）5分」で現場から工作物の外形を蒸発させることで、強制執行の手続きそのものを成立不能（Null）に追い込む。

## 1. 物理設計基本要件（Physics & Mechanics）

```text
　　　　　　　　 [テンション膜（高撥水・遮熱透湿シート）]
                   🔽　　　　　　　 　　　　　　　🔽          
　[軽量テンションフレーム] ── (M16ピン結合) ── [竹集成材 / 薄肉パイプ]
                   │                             │
                   │                             │
[地上レベル] ───────┴─────────────────────────────┴───────────────
 ▲ 地盤への基礎打設・アンカー打ち込みは【完全禁止】
 ▼ 自重・土嚢バラスト（現地発生土・砕石RC-40）による面接地
```
---

### 1.1 基礎ゼロ原則（Zero-Anchor Requirement）
* 地盤に対する杭打ち（グランドアンカー）、ケミカルアンカー、コンクリート打設を**仕様レベルで固く禁止**する。

* すべての接地部は、幅200mm以上のフラットベースプレート（ゴムまたは再生樹脂パッド付き）による「面圧分散・載置（置くだけ）」とする。

* 浮き上がり・転倒防止には、現地調達の土・砂・砕石（RC-40）を詰めた「可動式バラスト土嚢（20kg/袋 × 4〜8袋）」を自重ウェイトとしてフレーム基部に載置する。

### 1.2 構造・部材規格（Modular Components）
* **骨組（Framework）**:
  * 外径φ31.8mm〜φ48.6mmの薄肉高張力鋼管、または乾燥竹集成材（現地調達可能材）。
  * 接合部はボルト締め工具を最小化するため、単一規格の **M16戻り止めピン** または **カムロック式クランプ** に統一。1名かつ素手〜ラチェット1本で組立・解体可能とする。

* **外皮（Skin）**:
  * 軍用リップストップ加工を施した不燃・撥水・UV遮断透湿シート（四隅ハトメ付き）。
  * 引裂強度 1.2kN以上。強風時はあえてファスナーを開放して風を逃がす「風圧逃がし弁（Blow-out Slit）」を標準装備。

## 2. 状態遷移プロトコル：Deploy ＆ Melt

```text
　　　　　　　　15分展開         　 　         5分溶解    
【Pack 状態】───────────⏩️ 【Deploy 状態】 ───────────⏩️ 【Melt 状態】
  (資材・荷物)               (避難シェルター)               (無害化・分散) 
```
---

### 2.1 展開（Deploy）手順（標準所要時間：12〜15分 / 2名）
1. **路面触診・敷設**: 泥濘や雨水流下を避けるため、透水シートを敷き、その上に断熱ダンボールまたは竹簀（たけす）を展開。
2. **フレーム自立**: ピン結合によりA型またはドーム型トラスを自重自立させる。
3. **バラスト載置**: 接地プレートに土嚢を載せ、鉛直荷重を確保（耐風速 15m/s担保）。
4. **膜展張**: テンションコードで膜を骨組みに緊結。即座に雨風をしのぐ閉鎖空間が成立。

### 2.2 溶解（Melt）手順（緊急所要時間：3〜5分 / 任意人数）
行政職員、警察官、警備員等の臨場、または代執行の通告があった場合、以下の手順で直ちに構造物を「消滅」させる。

1. **被覆解除（1分）**: テンションコードを一気に引き抜き、膜シートを畳んで大型リュックまたは台車へ収納（この時点で「建物」としての外観が消失）。
2. **バラスト還元（1分）**: 土嚢の口を開け、中の土・砕石を植栽枡や側溝の隙間、路面の窪み（ポットホール）へ投棄・還元（ただの土砂に戻る）。
3. **骨組離脱（2分）**: M16ピンを引き抜き、パイプをバラして束ねる。
4. **完了状態（Melted）**: 現地に残るのは「歩道・広場に佇み、荷物（パイプの束とリュック）を持って立ち止まっている通行人」のみ。

## 3. 対行政・法執行空振りマトリクス

行政機関が強制力を発動しようとした際の、法令要件と本プロトコルの力学対比。

| 行政の攻撃手口 | 根拠条文 | SPNP/FSNPの対抗・無効化状態 |
| :--- | :--- | :--- |
| **「工作物を撤去せよ」** | 道路法第71条<br>都市公園法第6条 | 基礎が存在せず、5分で分解されて「手荷物」と化すため、撤去を命じるべき「工作物・物件」の特定が法理上不可能となる。 |
| **「行政代執行の令状を交付する」** | 行政代執行法第3条<br>（戒告・通知） | 令状に記載された「物件の形状・寸法」と、臨場時の「荷物状態」が一致しないため、執行官は令状執行不能（空振り）に陥る。 |
| **「不法占拠である」** | 刑法第235条の2<br>（不動産侵奪） | 地面に一切固着しておらず、境界エアポケットを日々移動するため、「平穏公然たる排他的占有の継続」が立証できない。 |

## 4. 現場土木・居住環境維持仕様（Ground-Truth Engineering）

ただ法をすり抜けるだけでなく、過酷な生の底にいる民草が体調を崩さないための現場工学。

* **地温遮断（Thermal Barrier）**:
  * アスファルトや土からの底冷え（伝導熱損失）を防ぐため、接地面には「空気層を含む再生発泡パレット（高さ100mm）」または「籾殻（もみがら）充填袋」を敷設。

* **雨水・結露処理（Hydraulic Breathing）**:
  * 幕体内外の温度差による結露を防ぐ二重天幕構造。
  * シェルター周囲に幅100mm・深さ50mmの仮設スリット（簡易額縁明渠）を掘り、雨水の浸入を物理遮断。解体時は足で土を均して平坦に戻す。

* **生活痕跡のゼロ化（Leave No Trace）**:
  * 撤収時にゴミ、汚水、油煙を一切残さない。生活痕跡を残さないことが、行政に「衛生上の危害（不潔物）」を口実にした介入を許さない最大の防壁となる。
