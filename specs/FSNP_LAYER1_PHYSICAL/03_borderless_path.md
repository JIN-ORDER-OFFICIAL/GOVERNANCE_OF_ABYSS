## 0. 目的と境界線分断の解体（Territorial Dissolution）

近代国家の統治機構は、大地を「道路法」「河川法」「都市公園法」「国有財産法」「私法上の所有権」によってパッチワーク状に細分化し、それぞれの境界線に「管理権限」と「排除命令権」を配備することで民草を包囲してきた。  
しかし、これら行政組織の縦割り構造は、現場において「管轄の隙間（無主のエアポケット）」と「管轄権争いによる法執行の硬直」という巨大な構造的欠陥を抱えている。

本仕様は、行政組織間の境界未画定地、暗渠上部、高架下側道、緑道結節点を一連の「動的避難回廊（Sanctuary Corridors）」として再定義する。  
定住して排除の標的となるのではなく、境界のエアポケットを循環・渡り鳥運用することで、あらゆる行政処分・代執行手続きを永遠に空転させる。

## 1. 狙い撃つ「5大法的エアポケット」（Jurisdictional Air Gaps）

```text
[高架高速道路 / 鉄道高架]（NEXCO / JR・私鉄管理）
  │
  ├─⏩️【隙間 1: 境界未確定地・保安緩衝帯】── 法的境界線の宙づり地帯
  │
[一般国道 / 県道 / 市道]（道路局管理：道路法）
  │
  ├─⏩️【隙間 2: 道路法第91条・未利用道路敷】── 道路区域内だが未供用の余剰地
  │
[せせらぎ緑道 / 都市暗渠]（水環境課 / 公園緑地課 / 下水道局）
  │
  ├─⏩️【隙間 3: 公図混乱地・河川旧悪水路】── 明治期字図と現況不整合地
  │
[普通河川 / 崖地法面]（河川局 / 港湾局 / 防災課）
```
---

### 1.1 隙間 1: 交通インフラ交差部の管轄盲点
* 高架道路・鉄道高架と、直下の市道・歩道が交差する立体空間。
* 柱から外側50cmの「鉄道保安敷」と「道路側溝敷」の間には、どちらの管理台帳にも明確な占有区分が記されていない「不確定緩衝帯」が数万箇所存在する。

### 1.2 隙間 2: 河川暗渠・旧水路上の歩行路（せせらぎ緑道等）
* かつて農業用水路・悪水路であった場所を暗渠化し、上部を緑道化した空間。
* 地目は「用悪水路（法定外公共物）」のまま、管理のみ下水道局や土木事務所が暫定的に行っているケースが多く、道路法の排他的適用が極めて困難な法的避難地となる。

### 1.3 隙間 3: 官民境界・公図不整合地（無登記・未買収地）
* 都市区画整理の網の目から漏れた三角地、旧公図（字図）と現況測量が一致せず、役所側も所有権・管理権の特定に数ヶ月の測量調査を要する宙づり地帯。

## 2. 渡り鳥プロトコル：動的移動ルーティング（Migratory Flow）

強制排除の手続きを常に時間切れ（Timeout）にするための空間移動規律。

```text
[拠点 A: 市道側余剰地] ──(戒告書交付・調査開始)──⏩️ [拠点 B: 鉄道高架下緩衝帯]
　　　　　⏫️           　　　                                  │
          │                   　　　　　　            (管轄照会・協議発生)
          │                              　　　　　　　        ⏬️
[拠点 D: 法定外暗渠緑道] ⏪️──(管轄不一致・手続失効)─── [拠点 C: 県管理法面隙間]
```
---

### 2.1 行政執行タイマーの空振り計算法
* 行政代執行法の手続きサイクル:
  1. 現場現況調査・占有者特定（所要: 1〜2週間）
  2. 道路法第71条に基づく監督処分・除却指導書の貼付（所要: 数日〜1週間）
  3. 行政代執行法第3条に基づく戒告（相当の猶予期間付与: 2週間〜1ヶ月）
  4. 代執行令状の交付

* **JIN-ORDER移動間隔**: **最長「7日〜10日」サイクル**で隣接する別管轄のエアポケットへノードを巡回移動させる。

* **効果**: 管轄権者（A市道路局）がようやく戒告書を発行した段階で、民草は既に「B鉄道敷」または「C水路暗渠」へ移動完了している。A市の令状は執行不能となり、手続きは最初からやり直し（Reset）となる。

## 3. 回廊内における民草物理動線の確保（Corridor Engineering）

回廊を通過・滞在する際、一般市民の歩行や生活を絶対に妨害せず、むしろ防犯・清掃・保全に寄与する設計基準。

* **有効幅員2.0mの死守**:
  * 道路構造令および歩行者安全基準に準拠し、歩行空間・車椅子通行幅（最低1.5m、推奨2.0m）を絶対に侵食しない配置をとる。

* **ポットホール（舗装陥没）即時塞ぎ（Guerilla Pavement Maintenance）**:
  * 回廊沿いの生活道路に発生したポットホールや段差を、ノードが携行する常温合材・RC-40で自発的に埋め戻す。
  * 「道路を荒らす不法者」ではなく、「地域の安全を無償保全している存在」として近隣住民と事実上の不可侵・共生合意を結ぶ。

* **愛犬散歩・生活見守りとの偽装調和**:
  * シェルター資材は「大型キャリーカート」「台車」「犬の散歩用ワゴン」に偽装・積載。
  * 朝夕の散歩時間帯には地域犬パトロールと同期し、街灯の玉切れや側溝の詰まりを行政より先に見つける「現場センサー」として機能する。

## 4. 法執行官との対話・脱力化コード（Civil Defense De-escalation）

警察官・行政パトロール職員と接触した際の、現場即応問答プロトコル。

1. **「ここで何をしているのか」**:
   * *応答*: 「移動中の手荷物を一時的に置き、体調を整えております。道路の通行幅2mを確保し、ゴミ拾いを行っておりました。」（占有の継続性を否定し、一時的滞留を主張）。

2. **「名前と住所を言え」**:
   * *応答*: 「憲法上の黙秘権に基づき、不要な個人情報の供述は差し控えます。緊急搬送の必要はありません。直ちに移動準備に入ります。」（身元特定をプロトコルレベルで拒絶）。

3. **「いつ立ち退くのか」**:
   * *応答*: 「体調が回復し次第、直ちにこの荷物を持って移動します。」（固定工作物でないことをアピールし、即時 Melt 状態へ移行）。
