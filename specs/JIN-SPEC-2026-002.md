## 1. 概要（Executive Summary）

![自律機構境界管理仕様](../assets/JIN-SPEC-2026-002_01.jpg)

本仕様書は、中央集権的統治機構による「空間台帳の歪曲（メルカトル的縮尺操作による周縁インフラの不可視化）」、「自律エージェントの無責任な兵器化・統制逸脱」、ならびに大型開発事業等における「合意形成ロンダリング」および「官民利益相反（公金還流）」を抑止し、公正かつ不可逆な調停秩序を工学的に担保するためのプロトコル要件を定義する。

深淵（ABYSS）および外延工区が担う膨大なインフラ維持管理負荷は、旧OSの恣意的な射影・台帳システムによって意図的に矮小化されてきた。さらに、机上の数字操作（費用便益比B/Cの偽装・再算定放棄）や外郭・民間団体を介したガバナンスロンダリングにより、民草の富と土地が収奪されている。  
JIN-ORDERは、空間台帳の「等積実体保証」（Isomorphic Mapping）、自律ユニットの「階層型自律境界」（Graduated Autonomy Boundary）、および「不可逆的合意形成監査」をコードとして固定し、認知・空間・統治の覇権構造を物理的・数理的に無力化する。

## 3. 3層統治・境界アーキテクチャ（Three-Tier Governance Architecture）

```text
[Layer 2: Benevolent Arbitration] ⬅️ 仁愛調停エンジン（不可逆的孤立化・合意偽装の自動棄却）      
[Layer 1: Graduated Autonomy]     ⬅️ 階層別自律制限（Level 1〜5 実行境界）& 利益相反遮断      
[Layer 0: Isomorphic Ledger]      ⬅️ 等積実体空間台帳 & 不可逆的B/C・財務監査台帳
```
---

### 3.1 Layer 0: 等積実体空間台帳（Isomorphic Ledger）
物理的空間・土木構造物・事業評価の実態を歪曲なく記録するデータ層。

- **等積射影（Isomorphic Mapping）のハードコード**  
  中心部を過大表示し周縁部を矮小化する図法（旧メルカトル型空間認識）を全廃。地下深度、配管容積、土圧負荷を等体積比率でブロックチェーン台帳に記録。

- **物理インフラ原価 & B/Cの完全可視化**  
  各工区の維持管理にかかる実土木コスト（管渠更生、土砂浚渫、換気動力）を台帳に直結。事業計画に変更（新交通システムの断念、ルート変更等）が生じた場合、人間側の恣意的判断を介さず、自動的に費用便益比（B/C）を再算定して公開台帳へコミットする。

### 3.2 Layer 1: 階層型自律境界（Graduated Autonomy Layer）
インフラを自律維持するエージェント群に対する権限レベルの厳格区分、および統治者の利益相反排除。

- **Level 1〜2（局所自律 / Local Autonomous）：**  
  配管亀裂の自動補修、側溝浚渫、定期巡回など、可逆性が高く他区画に影響しない保守タスクは完全自律実行。

- **Level 3〜4（広域連動 / System-Wide Coordination）：**  
  主幹ゲートの開放・閉鎖、幹線交通ルートの改廃、大規模公金支出など、都市区画に不可逆的影響を与える操作には「人間・工区代表合議体の多重署名（Multi-Sig）」を必須化。

- **Level 5（統治規範 / Core Protocol）：**  
  自律エージェントが自身の行動倫理やライセンス規定を自己改変することは物理ROMレベルで永久遮断。

- **責任の不可分性（The Undelegated Warden）**  
  すべての自律ユニットおよび行政決裁には物理的・法的な「署名責任者（Keyholder）」の公開鍵を紐付け、「機械の誤認」や「組織の決定」による免責を不許可とする。

- **官民境界インターロック（Conflict-of-Interest Interlock）**  
  公的インフラ計画の意思決定者が、事業受託企業・推進民間団体の役員や顧問を兼任している場合、当該ノードの決裁権限および公金執行トランザクションをスマートコントラクトにより即座に自動凍結（Freeze）する。

### 3.3 Layer 2: 仁愛調停カーネル（Benevolent Arbitration Layer）
紛争・対立・行政不正発生時に自動発動する安全保障プロトコル。

- **「Anti-Isolation（反孤立化）」プロトコル**  
  いかなる勢力も、特定工区のライフライン（送風・排水・最低限エネルギー）を交渉材料として遮断することを禁止。遮断命令が発行された場合、カーネルが自動的に拒否権（VETO）を発動し、バイパスラインを自律開放する。

- **合意形成ロンダリング無効化ゲート（Consensus Sanitizer）**  
  実態のない形式的公聴会や不透明なパブリックコメントによる事業推進を「無効なトランザクション」として棄却。利害関係を有する地域住民・現場労働者の零知識暗号投票による直接合意率（Proof-of-Consent）が閾値（80%）に達しない計画は自動凍結される。

## 4. 境界侵犯・調停シーケンス（Arbitration Sequence）
結節点封鎖、台帳改竄、または合意形成偽装が発生した際の自律調停モデル：

```コード スニペット
stateDiagram-v2
    [*] --> Synchronized: 正常等積台帳・分散運用
    
    state Alert_Trigger {
        Synchronized --> Boundary_Alert: 結節点閉鎖 / 台帳改竄検知
        Synchronized --> Fraud_Alert: B/C再算定放棄 / 利益相反癒着検知
    }

    state Arbitration_Lock {
        Boundary_Alert --> Bypass_Routing: ライフライン迂回バイパスの強制開放
        Fraud_Alert --> Freeze_Authority: 該当幹部ノードの決裁権限・公金執行凍結
        
        Bypass_Routing --> Audit_Ledger: 等積台帳による実負荷・侵犯ログ監査
        Freeze_Authority --> Recalculate_BC: パラメトリックB/C自動再検証
        
        Audit_Ledger --> Multi_Sig_Hearing: 工区市民合議体による署名検証
        Recalculate_BC --> Multi_Sig_Hearing
    }
    
    Arbitration_Lock --> Restored_Equilibrium: 均衡回復・新調停協定のコミット
    Restored_Equilibrium --> Synchronized: 正常運用へ復帰
```
---

1. **フェーズ1（検知）：** 幹線バルブの不当閉鎖、空間縮尺改竄、または事業前提崩壊に伴うB/C再算定のサボタージュをメッシュが検知。
2. **フェーズ2（インターロック）：** 侵犯ノードのLevel 3以上権限を即時停止し、癒着・背任ノードの公金執行を凍結。
3. **フェーズ3（仁愛バイパス & 自動再計算）：** 「Nobody Cries」原則に基づき、生命維持流路を迂回路へ強制切り替え、同時に真のB/Cを客観データから即時再出力。
4. **フェーズ4（公開調停）：** 改竄不能な等積台帳ログに基づき、市民合議体による多重署名調停を実施。

## 5. 憲章条文（Codified Articles）

本仕様書の内容は、直ちに『JIN_FRONTIER_LAW.md（開拓地特別法）』の第IV章として法制化される。

- **第12条（空間台帳の等積保証）**  
  統治機構は、すべての深度・工区における物理空間の占有実態を等積射影（Isomorphic Mapping）によって開示しなければならない。中心部の権能拡大を目的とした測量データの縮尺操作は、重大な統治協定違反とみなす。

- **第13条（自律維持機構の封じ込め原則）**  
  インフラ維持を担う自律エージェントの行動権限は、物理的影響の不可逆性に応じて厳格に階層化される。いかなる自律機構も、特定工区の遮断・孤立化を単独で決定することはできず、必ず当該境界に属する市民合議体の二重鍵署名を要する。

- **第14条（幹線結節点の共有地性）**  
  上下水道、換気立坑、主幹導管等の重要結節点を占有するセクターは、他セクターへの供給を人質とした一方的な協定変更を行ってはならない。

- **第15条（事業評価の不可逆性および合意形成ロンダリングの禁止）**  
  都市インフラ・交通計画における主要前提の変更（新交通システムの撤回、ルート変更、資材価格急騰等）が発生した場合、統治機構は遅滞なく客観的費用便益比（B/C）を再算定し公開しなければならない。これを怠り、形式的な協議体を介して民意を偽装する行為（合意形成ロンダリング）は、即時に予算執行停止の対象となる。

- **第16条（官民境界の分離および利益相反の自動排除）**  
  インフラ計画の立案・承認権限を有する行政幹部は、当該計画から直接的・間接的利益を享受する民間団体、推進組織、外郭法人の役員に就任してはならない。職務専念義務の免除等を用いてこれらを迂回する行為は統治協定違反とし、すべての決裁トランザクションは自動破棄される。
