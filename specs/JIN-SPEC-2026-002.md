## 1. 概要（Executive Summary）

本仕様書は、中央集権的統治機構による「空間台帳の歪曲（メルカトル的縮尺操作による周縁インフラの不可視化）」および「自律エージェントの無責任な兵器化・統制逸脱」を抑止し、公正かつ不可逆な調停秩序を工学的に担保するためのプロトコル要件を定義する。

深淵（ABYSS）および外延工区が担う膨大なインフラ維持管理負荷は、旧OSの恣意的な射影・台帳システムによって意図的に矮小化されてきた。<br>
JIN-ORDERは、空間台帳の「等積実体保証」（Isomorphic Mapping）と、自律ユニットの「階層型自律境界」（Graduated Autonomy Boundary）をコードとして固定し、認知と自律の覇権争いを無力化する。

## 3. 3層統治・境界アーキテクチャ（Three-Tier Governance Architecture）

```text
[Layer 2: Benevolent Arbitration] ⬅️ 仁愛調停エンジン（不可逆的孤立化の自動棄却）      
[Layer 1: Graduated Autonomy]     ⬅️ 階層別自律制限（Level 1〜5 実行境界）      
[Layer 0: Isomorphic Ledger]      ⬅️ 等積実体空間台帳（物理体積・実延長の不可変記録）
```
---

### 3.1 Layer 0: 等積実体空間台帳（Isomorphic Ledger）
物理的空間・土木構造物の実態を歪曲なく記録するデータ層。

* **等積射影（Isomorphic Mapping）のハードコード**  
  中心部を過大表示し周縁部を矮小化する図法（旧メルカトル型空間認識）を全廃。地下深度、配管容積、土圧負荷を等体積比率でブロックチェーン台帳に記録。

* **物理インフラ原価の完全可視化**  
  各工区の維持管理にかかる実土木コスト（管渠更生、土砂浚渫、換気動力）を台帳に直結し、不当な配分不均衡を数理的に証明・是正する。

### 3.2 Layer 1: 階層型自律境界（Graduated Autonomy Layer）
インフラを自律維持するエージェント群に対する権限レベルの厳格区分。

* **Level 1〜2（局所自律 / Local Autonomous）：**  
  配管亀裂の自動補修、側溝浚渫、定期巡回など、可逆性が高く他区画に影響しない保守タスクは完全自律実行。

* **Level 3〜4（広域連動 / System-Wide Coordination）：**  
  主幹ゲートの開放・閉鎖、幹線電力系統の遮断など、都市区画に不可逆的影響を与える操作には「人間・工区代表合議体の多重署名（Multi-Sig）」を必須化。

* **Level 5（統治規範 / Core Protocol）：**  
  自律エージェントが自身の行動倫理やライセンス規定を自己改変することは物理ROMレベルで永久遮断。

* **責任の不可分性（The Undelegated Warden）**  
  すべての自律ユニットには物理的・法的な「署名責任者（Keyholder）」の公開鍵を紐付け、「機械の誤認」による免責を不許可とする。

### 3.3 Layer 2: 仁愛調停カーネル（Benevolent Arbitration Layer）
紛争・対立発生時に自動発動する安全保障プロトコル。

* **「Anti-Isolation（反孤立化）」プロトコル**  
  いかなる勢力も、特定工区のライフライン（送風・排水・最低限エネルギー）を交渉材料として遮断することを禁止。遮断命令が発行された場合、カーネルが自動的に拒否権（VETO）を発動し、バイパスラインを自律開放する。

## 4. 境界侵犯・調停シーケンス（Arbitration Sequence）
特定セクターによる結節点封鎖や空間データ改竄が発生した際の自律調停モデル：

```mermaid
stateDiagram-v2
    [*] --> Synchronized: 正常等積台帳・分散運用
    Synchronized --> Boundary_Alert: 結節点閉鎖 / 台帳改竄シグナル検知
    Boundary_Alert --> Arbitration_Lock: 該当ノードの自律実行権を一時凍結
    state Arbitration_Lock {
        [*] --> Bypass_Routing: ライフライン迂回バイパスの物理強制開放
        Bypass_Routing --> Audit_Ledger: 等積台帳による実負荷・侵犯ログ監査
        Audit_Ledger --> Multi_Sig_Hearing: 工区市民合議体による署名検証
    }
    Arbitration_Lock --> Restored_Equilibrium: 均衡回復・新調停協定のコミット
    Restored_Equilibrium --> Synchronized: 正常運用へ復帰
```
---

1. **フェーズ1（検知）：** 幹線バルブの不当閉鎖、または空間縮尺の改竄データをメッシュが検知。
2. **フェーズ2（インターロック）：** 侵犯ノードのLevel 3以上権限を即時停止。
3. **フェーズ3（仁愛バイパス）：** 「Nobody Cries」原則に基づき、生命維持流路を迂回路（バイパス）へ強制切り替え。
4. **フェーズ4（公開調停）：** 改竄不能な等積台帳ログに基づき、合議体による調停を実施。

## 5. 憲章条文（Codified Articles）

本仕様書の内容は、直ちに『JIN_FRONTIER_LAW.md（開拓地特別法）』の第IV章として法制化される。

* **第12条（空間台帳の等積保証）**  
  統治機構は、すべての深度・工区における物理空間の占有実態を等積射影（Isomorphic Mapping）によって開示しなければならない。中心部の権能拡大を目的とした測量データの縮尺操作は、重大な統治協定違反とみなす。

* **第13条（自律維持機構の封じ込め原則）**  
  インフラ維持を担う自律エージェントの行動権限は、物理的影響の不可逆性に応じて厳格に階層化される。いかなる自律機構も、特定工区の遮断・孤立化を単独で決定することはできず、必ず当該境界に属する市民合議体の二重鍵署名を要する。

* **第14条（幹線結節点の共有地性）**  
  上下水道、換気立坑、主幹導管等の重要結節点を占有するセクターは、他セクターへの供給を人質とした一方的な協定変更を行ってはならない。
