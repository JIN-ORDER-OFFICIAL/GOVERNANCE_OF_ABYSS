## 目的と台帳管理の無効化（Abolition of Registry Hegemony）

近代国家およびデジタル監視資本主義が民草を家畜化する第一歩は、「ID（識別番号）の付与と台帳（データベース）による名寄せ」である。  
戸籍、マイナンバー、社会保障番号、生体認証、決済履歴、通信ログを単一の主権データベースへ紐付けることで、国家は「従順な民」には配給を与え、「異分子・困窮者」をシステムから不可視化・排除・兵糧攻めにしてきた。

本仕様は、SPEC-000（魂の不可測性）を通信・認証レイヤーで直接具現化する。  

「個人を特定する一切の情報（属性・履歴・生体データ）を差し出すことなく、ただ『今、そこに一人の生命として息づいている』という客観的事象のみを数学的に証明する」ことで、国家やプラットフォームによる捕捉・名寄せ・選別をプロトコルレベルで拒絶する。

### 1.1 属性ゼロ原則（Zero-Attribute Ingestion）
* システムは、氏名、年齢、性別、国籍、住所、マイナンバー、顔写真、電話番号等の入力を**スキーマ（データ定義）レベルで受領拒絶（Syntax Error）**する。

* 認証パケットに許容されるペイロードは、以下の3要素のみとする：
  1. **生存エポック証明（$Proof_{\text{alive}}$）**: 暗号学的に生成された「今生きている」というゼロ知識証明。
  2. **揮発性近接フラグ（Proximity Token）**: 最寄りのノードと通信するためのワンタイム使い捨てトークン。
  3. **状態コード（Status Byte）**: `NORMAL`（平穏）または `SOS_RESOURCE`（水・食・医療等の要請）の1バイトのみ。

### 1.2 揮発性・使い捨てID（Ephemeral Session Key）
* 端末ごとに固定されたMACアドレス、UUID、公開鍵を長期間保持することを禁止する。

* 1回の通信セッション（または一定時間経過、最長180分）ごとに鍵ペアを完全破棄・再生成し、国家のトラフィック監視AIによる「同一人物の行動追跡（トラッキング）」を計算量的に不可能にする。

## 2. 暗号工学実装仕様（Cryptographic Mechanics）

ゼロ知識証明（zk-SNARKs / Halo2）を軽量化し、市販の安価なスマートフォンやマイコン（ESP32・Raspberry Pi等）でオフライン稼働させる設計。

### 2.1 生存証明生成回路（Proof of Life Circuit）
民草の端末は、ローカル環境（外部非公開）で微弱な生体乱数（タップ間隔のゆらぎ、歩行振動センサー値、または端末の微小熱雑音）をシードとして一時ハッシュを生成し、以下の命題を証明する回路を実行する。

$$\text{Circuit Statement: } \mathcal{R} = \{ (x, w) \mid x = \text{Hash}(w) \land \text{IsHumanEntropy}(w) = \text{True} \}$$

* **公開入力（Public Input $x$）**: ネットワークに流れる検証可能な証明ハッシュ値。
* **秘密証拠（Witness $w$）**: 端末内部で生成された生体ゆらぎデータ（外部には1ビットも漏洩しない）。
* **検証結果**: メッシュ内の他ノードは、「人間が操作して生成した正規の生存シグナルである」ことのみを0ミリ秒で数学的に確認でき、その人物が誰であるかは一切知ることができない。

### 2.2 ログの完全揮発消却（Volatile Node Policy）
* メッシュの中継ノード（リレーノード）は、パケットを隣接ノードへ転送した瞬間、または支援物資の受け渡しが完了した瞬間に、該当トランザクションの通信ログをRAM（オンメモリ）上から**ゼロフィル上書き消去（Zeroization）**しなければならない。
* ストレージ（SSD/Flash）への通信ログ書き込みはプロトコル違反とし、ノード権限を自動遮断する。

## 4. 現場運用SOP：端末を持たない民草の接続（Analog Bridge）

端末を持たない、あるいはデジタル機器を破棄して逃げてきた民草を包摂するための現場運用。

1. **オフライン・物理トークン交付**:
   * 避難回廊（SPEC-003）の給水所や炊き出し所に立ち寄った際、使い捨ての「暗号化QR木札」または「RFIDタグ付き端切れ」を無言で手渡す。

2. **完全無審査の即時認証**:
   * その木札を読み取り機にかざすだけで、水槽の電磁弁が開き、孝弁（弁当）が提供される。
   * 木札には通し番号すら振られておらず、ただ「有効な署名が1つ入っている」ことだけが照合されるため、誰が持参したかを特定することは物理的に不可能である。
