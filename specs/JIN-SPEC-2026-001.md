## 1. 概要（Executive Summary）

本仕様書は、国家間の軍事的威嚇や国際通商航路の遮断（ホルムズ海峡、バブ・エル・マンデブ海峡、特定送電網・海底パイプライン等）によって引き起こされる「エネルギー兵糧攻め」、および巨大AIデータセンター等の計算インフラによる「平時電力寡占・生活費高騰（アフォーダビリティ危機）」を工学的に無効化（Invalidate）するための技術・土木・通信プロトコル要件を定義する。

旧世代の国家秩序および資本構造において、エネルギーは中央集権的チョークポイントを握る覇権国・巨大テック資本の「威嚇カード（Leverage）」および「資産吸い上げ装置」として機能してきた。JIN-ORDERは、エネルギー主権を大地（Local Ground）と自律プロトコル（Autonomous Protocol）へ還元することで、外部遮断や市場暴騰が発生した瞬間に物理的・自動的に自己完結する「不沈型分散エネルギーメッシュ」を構築する。

## 3. 3層防御アーキテクチャ（Three-Tier Architecture）

```text
[Layer 2: Benevolent Kernel] ⬅️「Nobody Freezes / Nobody Starves」アフォーダビリティ死守配分
       
[Layer 1: Autonomous Mesh]  ⬅️ P2P 電力ルーティング & AI計算負荷動的抑制（Curtailment）
       
[Layer 0: Hardened Ground]  ⬅️ 深層地熱・小水力・都市バイオマス・地下分散備蓄セル
```
---

### 3.1 Layer 0: 物理基盤層（Hardened Ground）
外部補給線が100%途絶、または市場価格が天文学的急騰を起こした場合でも、最低180日間の地域完全自律生存を担保する物理土木層。

- **深層地熱・小水力・分散バイオマスの基底化**  
  天候依存型（メガソーラー・大型洋上風力）に過度に依存せず、地下熱源、自律水系、下水処理フォトバイオリアクター（都市バイオマス原油）から直接取得する「外乱ゼロ型ベースロード」を各拠点に標準実装する。

- **物理防護型地下エネルギーセル（Civil Bunkering）**  
  蓄電池群および水素／アンモニア吸蔵合金タンクは地下土木工法によりシェルター化し、物理空爆・EMP（電磁パルス）攻撃から防護する。

- **AIデータセンター・オフグリッド自給原則（Off-Grid Self-Generation Mandate）**  
  系統電力を圧迫するメガワット級AIコンピュートノードは、公共系統へのフリーライド・優先受電を禁止する。事業者自身の責任によるLayer 0電源（地熱・都市バイオマス・未利用排熱発電）の直接併設を物理要件とする。

### 3.2 Layer 1: 自律メッシュ制御層（Autonomous Mesh Layer）
中央指令所を不要とする分散台帳連動型のグリッド制御。

- **動的アイランディング（Dynamic Autonomous Islanding）**  
  広域系統網で異常電圧降下、周波数破壊、または物理切断を検知した場合、ミリ秒単位で中央グリッドから自律切断。マイクログリッドとして瞬時に独立稼働する。

- **P2P零知識電力ルーティング**  
  各エネルギー生成ノードは、暗号化された通信プロトコルを用いて隣接ノードと需給調整を実施。単一障害点（SPOF）となる中央集中型送配電センターを完全排除する。

- **コンピュート負荷動的抑制（Compute Curtailment Protocol）**  
  系統全体の受給バランスが逼迫（予備率3%割れ等）した際、AI計算ノードへの給電をミリ秒単位で自動デタッチ（切断）または低クロック制限するハードウェア・インターロックを義務化する。

### 3.3 Layer 2: 仁愛カーネル層（Benevolent Kernel Layer）
供給能力が物理的限界値以下へ逼迫した際、または市場価格が高騰した際の自律優先度制御。

- **「Nobody Freezes / Nobody Starves」プロトコル**  
  市場原理（価格急騰による持たざる者の切り捨て）を拒絶。電力および熱量は以下の厳格なプライオリティ・キューに従って自動配分される：
  1. **Priority-0 (Critical):** 生命維持施設（救急病院、給水施設、人工透析、避難シェルター）
  2. **Priority-1 (Core):** 食料保存・調理施設、最低限の地域防護通信メッシュ
  3. **Priority-2 (Standard / Affordability Anchor):** 一般家庭用最低限冷暖房・給湯・照明（※市場連動を完全遮断・固定供給）
  4. **Priority-3 (Deferrable):** 一般商業活動・オフィス空調・一般産業用動力（一時的自動デタッチ・セーブ運転）
  5. **Priority-4 (Curtailable):** AIモデル訓練・大規模データセンター・暗号資産マイニング（系統逼迫時に即時強制遮断）

- **アフォーダビリティ・アンカー（Affordability Anchor）**  
  Priority-2までの民生用基本エネルギー供給は、国際市場・為替・先物投機の変動レートから完全に隔離（Air-gap Pricing）。J-Log（倫理貢献度）および実物資源ベースの固定コストによりゼロマージンで供給される。

## 4. チョークポイント無力化 & アフォーダビリティ防衛シーケンス
地政学的有事（主要海峡封鎖等）またはテック資本による電力収奪が発生した際のシステム遷移モデル：

```コード スニペット
stateDiagram-v2
    [*] --> Normal_Mode: 通常メッシュ連系運転
    
    state Crisis_Detection {
        Normal_Mode --> Chokepoint_Alert: 海峡封鎖 / 燃料輸入停止アラート
        Normal_Mode --> Grid_Drain_Alert: AI電力貪食 / 系統予備率逼迫アラート
    }

    state Sovereign_Decoupling {
        Chokepoint_Alert --> Activate_Layer0: 地下基底電源・地熱出力最大化
        Grid_Drain_Alert --> Curtail_Compute: Priority-4 (AI計算) を即時遮断
        
        Curtail_Compute --> Protect_Civil: Priority-2 (民草生活電力) を固定防護
        Activate_Layer0 --> Engage_Islanding: 広域系統からの動的アイランディング
        Protect_Civil --> Engage_Islanding
        
        Engage_Islanding --> Kernel_Priority: 仁愛カーネルによる厳格優先配分
    }

    Sovereign_Decoupling --> Autonomous_Sanctuary: 閉鎖循環型自律圏の確立
```
---

1. **フェーズ1（多角的検知）:** 国際供給網の停止、決済遮断シグナル、または大規模データセンターによる系統予備率危機シグナルを検知。
2. **フェーズ2（計算負荷の排除）:** 民草の生活基盤を守るため、系統にぶら下がる高負荷AI計算ノード（Priority-4）を自動解列。
3. **フェーズ3（デカップリング）:** 依存度が高い中央系統から即座にメッシュ単位へ解列（アイランディング）。
4. **フェーズ4（大地への回帰）:** 深層地熱・水力・都市バイオマス原油・地下吸蔵水素をフル駆動し、域内生存エネルギーを100%賄う。
5. **結果:** 外国の兵糧攻め、および金融・テック資本によるエネルギー収奪の力学が物理的・工学的に完全無力化される。
