## 概要：なぜ「権力無効化」が不可欠なのか

国家が提供する既存の公的福祉およびセーフティネットは、本質的に以下の致命的な脆弱性を抱えている。

1. **申請主義の暴力**: 飢え、凍え、疲れ果てた民草に「書類」と「自らの無力さの証明」を要求する。
2. **生殺与奪の独占**: 給付の可否を行政が握ることで、民草を国家の従属物へと飼いならす。
3. **財政・政治カード化**: 財政難や政権交代のたびにセーフティネットが削減され、最も弱い者が真っ先に切り捨てられる。

さらに、民草が自発的に助け合おうとすると、国家は「道路法違反」「都市公園法違反」「不法占拠」「未認可配給」を盾に行政代執行や警察力を投入し、その芽を摘み取ってきた。

**「守る仕組み（セーフティネット）」と「干渉を空振りに終わらせる盾（権力無効化）」は不可分の同一体でなければならない。**  
本プロトコルは、国家権力と暴力で正面衝突することなく、国家が権力を行使する「作用点」そのものを蒸発させ、民草の生存権を物理とデジタルの双方で自律担保する。

## 2. 国家権力の4大干渉に対する「無効化仕様」

### 2.1 【無効化 1】捕捉・台帳化の無効化（Identity Nullification）
* **対象レイヤー**: Layer 3（仁シグナル層）
* **国家の干渉手口**: マイナンバー、戸籍、生体認証による住民台帳管理。「登録された従順な民」にのみ配給を行い、反抗的な者を兵糧攻めにする。
* **SPNP実装仕様**:
  * **Zero-Proof Access**: 避難地や支援リソースへのアクセスに、氏名・国籍・属性の提示を一切要求しない。
  * **揮発型一時トークン（Ephemeral Peer ID）**: 救援要請や通信は、都度生成・破棄される使い捨て公開鍵によって行われ、監視AIによる行動履歴の名寄せ・追跡を不可能にする。

### 2.2 【無効化 2】接収・兵糧攻めの無効化（Seizure Nullification）
* **対象レイヤー**: Layer 2（自律分散コモンズ層）
* **国家の干渉手口**: 備蓄倉庫の捜索差押え、物資接収、兵站の封鎖。
* **SPNP実装仕様**:
  * **所有権の完全消滅（No-Owner Asset）**: 物資は特定の個人・団体の所有物ではなく、すべてパブリックドメイン（CC0）の自然遺棄物または共用財として配備される。差し押さえるべき「法的所有者」が存在しない。
  * **マイクロ超分散配備**: 巨大な集中型倉庫を造らず、民家の軒先、路傍の側溝、高架下、緑道植栽枡の隙間に「1〜2日分のキット」を無数に分散。強制執行にかかる行政・警察コストを回収価値より肥大化させ、取り締まりを経済的に破綻させる。

### 2.3 【無効化 3】首謀者処罰・組織分断の無効化（Headless Protocol）
* **対象レイヤー**: Layer 2 / 全体統治
* **国家の干渉手口**: リーダー、親分、代表者の逮捕による組織の機能停止と民草の分断。
* **SPNP実装仕様**:
  * **完全無頭アーキテクチャ（Headless Architecture）**: 組織規約から「代表者」「事務局長」「理事」等の役職を法理的・構造的に排除。
  * **公知手順書（Open Civil SOP）による自律実行**: 誰かがその場から離脱・拘束されても、別の民草が公開された仕様書（SOP）を読み、スコップと端末を手に取った瞬間に次の実行ノードとなる。逮捕すべき「首」が存在しない。

### 2.4 【無効化 4】強制排除・境界線の無効化（Spatial Nullification）
* **対象レイヤー**: Layer 1（大地の避難地層）
* **国家の干渉手口**: 道路法第32条（占用許可）、都市公園法、行政代執行法に基づくバリケード撤去・テント強制撤去・追い出し。
* **SPNP実装仕様**:
  * **非固着型インフラ（Deploy & Melt）**: 地面にアンカーボルトやコンクリート基礎を打たない。土嚢、テンション膜、可動式プランターを組み合わせ、数分で展開・撤収・変形できる柔構造を採用。令状が出た時点で「定着物（不動産）」としての法的要件を消失させる。
  * **管轄境界エアポケットの動的渡り鳥運用**: 道路局、河川局、鉄道事業者、民間地権者の管轄境界が曖昧な結節点（エアポケット）を巡回利用。行政代執行の管轄確定手続きの遅延を利用し、常に法執行の手の届かない間隙を泳ぎ続ける。

## 3. かつての「侠（遊侠）」の堕落を防ぐ防腐設計

歴史上、民草を救おうとした「裏のセーフティネット（侠客・義賊）」は、自らの私利私欲や権力化によって必ず腐敗し、民草を喰らう暴力団・利権屋へと堕落した。SPNPは、この人間の業を冷徹に防波堤で塞ぐ。

| 堕落の要因 | かつての侠・任侠集団 | SPNPによる防腐プロトコル |
| :--- | :--- | :--- |
| **権力構造** | 親分子分の上下関係・絶対服従 | **無頭（Headless）設計**。親分・幹部を構造的に作らせない |
| **資金源** | 縄張り（シノギ）と上前（ピンハネ） | **P2P実物互恵・中抜き不能台帳**。富の蓄積を許さない |
| **心理的支配** | 「助けてやった」恩義と暴力の鎖 | **無審査・無記名アクセス**。恩の貸し借り自体を成立させない |
